**Human Resources Attrition Analysis**

Dataset  
https://www.kaggle.com/datasets/mahmoudemadabdallah/hr-analytics-employee-attrition-and-performance?select=Employee.csv

**Project Overview**  
This project explores employee attrition using SQL, Excel, and Tableau. The dataset contains HR records for 1,470 employees.  
Through SQL queries and an interactive Tableau dashboard, I identified key trends in workforce turnover, built KPI-driven insights, and provided actionable recommendations for HR decision-making.

**Business Questions Answered**  
- What is the overall attrition rate and how does it vary by department?  
- Which job roles and age groups have the highest attrition?  
- Do overtime employees have higher attrition rates?  
- How does job satisfaction influence turnover?  
- How do salary and tenure differ across employees?  

**Tools & Skills Used**  
- SQL (PostgreSQL) → joins, aggregations, CTEs, window functions  
- Excel → exploratory analysis, validation  
- Tableau → interactive dashboards, KPI visualization  
- Data Storytelling → translating raw data into HR insights  

**Key Insights**  
- Overall attrition rate: **16.1%**  
- Highest turnover among employees aged **24–29**  
- Roles most affected: Data Scientist, Sales Executive, Software Engineer  
- Higher attrition among Computer Science & Marketing graduates
